# Growth Playbook

This repo is a niche utility project. The fastest path to traffic is not broad
AI hype; it is repeated, specific proof that the scripts solve painful Google
Ads jobs.

## Positioning

English one-liner:

> AI-assisted Google Ads Scripts for search term mining, negative keyword
> automation, keyword expansion, ad copy audits, and Sheets-based PPC reports.

Chinese one-liner:

> 一套把 OpenAI/Gemini 接进 Google Ads Scripts 的投放自动化脚本，用来做搜索词挖掘、否词、加词、文案覆盖检查和周/月报。

## Traffic Channels

| Channel | Why it can work | What to post |
| --- | --- | --- |
| GitHub search | Captures developer/operators searching for ready scripts. | Clear README, topics, frequent releases, practical file names. |
| Google search | Captures long-tail queries like "Google Ads negative keyword script". | Blog posts, GitHub README, examples with exact workflow names. |
| LinkedIn | Best for PPC operators, agency founders, and growth teams. | Before/after workflow posts with screenshots using fake data. |
| X / Twitter | Good for short technical threads and AI automation demos. | 5-tweet thread per script: pain, logic, setup, safety, repo link. |
| Reddit / PPC communities | High-intent practitioners, but avoid spam. | Share one useful workflow and explain tradeoffs; link repo at the end. |
| Zhihu / Xiaohongshu / Bilibili | Good for Chinese PPC and cross-border ecommerce audience. | "Google Ads 投放自动化脚本合集" tutorials and short demos. |
