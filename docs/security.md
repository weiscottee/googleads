# Security

This repository intentionally uses placeholder credentials only.

Before publishing or sharing Google Ads Scripts:

- Remove real API keys, spreadsheet IDs, account IDs, and client names.
- Rotate any API key that has ever been pasted into a shared document.
- Run a secret scan before pushing.
- Use the narrowest possible campaign filter during testing.
- Run Google Ads Scripts in preview mode before applying changes.

The packaged Gemini script was sanitized from a Google Docs source document. The
published version does not include the original API key or spreadsheet ID.
